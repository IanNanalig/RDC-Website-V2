# RDC-NCR Manual Beta-Testing Sample Data Kit

> **SAMPLE DATA - FOR RDC-NCR BETA TESTING ONLY**

This kit contains ten fictional Metro Manila project proposals and genuine, readable PDF supporting documents for manual entry through the existing application. It contains **no database fixture, account, validation record, AI result, or historical learning record**.

## Use this kit

1. Create and assign tester accounts using the normal application workflow.
2. Sign in as a Contributor whose primary agency matches the `Agency Name` in the selected project file.
3. Copy the values from `project-data/project-XX.md` into the Simplified RDIP Contributor Form.
4. Follow that file's supporting-document instruction. Upload PDFs manually through the application.
5. Use the testing-reference documents to coordinate ownership, document relevance, validation, and AI testing.

## Dataset coverage

- **10** distinct fictional proposals: DPWH, DOH, and DOTr are all represented.
- **2** DPWH-primary / DOTr-collaborating projects: Projects 04 and 05.
- **5** projects have relevant PDFs: Projects 01, 03, 04, 06, and 10.
- **3** projects start with no document: Projects 02, 05, and 07.
- **2** projects have an intentionally unrelated PDF: Projects 08 and 09.

Do not treat an AI recommendation as a validator-confirmed outcome. Validators must use the real review and confirmation workflow; no value in this kit claims an approval or endorsement.
