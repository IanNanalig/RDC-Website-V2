# RDC-NCR 10 Additional Project Beta-Testing Kit

This package contains Projects 11–20 from the detailed manual-entry dataset. It is separate from the earlier Projects 01–10 kit. These are generated internal testing materials, not real approved or funded government projects. No data has been inserted into the application.

## Contents

- Ten project entry sheets in `project-data/`, including project-specific Validator Facts Supplements.
- An Excel workbook with proposal fields, annual budgets, Validator inputs, and a separate scoring reference.
- Ten separate criterion-level reference sheets and a rubric reference in `scoring-references/`.
- Eight relevant PDFs and one intentionally unrelated PDF in `supporting-documents/`; Project 20 intentionally has no PDF.
- Project, collaboration, document, and implementation-status matrices in `testing-reference/`.

## How to use

1. Enter each proposal manually with a Contributor account linked to its primary agency. Do not import it directly into the database.
2. Upload only the PDF assigned to that project. The Project 16 PDF is deliberately unrelated; Project 20 has none.
3. Enter Validator Facts during review, then run the AI Assistant Scorer. Keep the reference priority and criterion scores away from form answers and uploaded evidence.
4. Compare results with the scoring reference only after analysis. Reference scores are testing expectations, not actual AI outputs or Validator decisions.

The current published Contributor Form and active AI rule version may differ from the repository defaults used to prepare this kit. Check their fields, options, required-document rule, and High threshold before data entry. Under a required-document rule, Project 20 is a missing-document validation case and cannot be submitted without changing that rule through the normal form workflow. All other proposal and validation steps remain manual.
